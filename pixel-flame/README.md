## 操作

在屏幕中央操作。

- 单击弹出火星。
- 双击切换颜色。
- 连续三击切换火苗形态。
- 连续四击切换体感开关，关闭体感后保持朝上燃烧。

体感开启时，竖起渐燃，横放或快晃渐熄，停稳后逐渐复燃。
熄灭时保留余烬。息屏显示低亮像素数字。
