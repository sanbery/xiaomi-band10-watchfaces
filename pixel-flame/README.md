## 功能

- 像素火焰配合顶部时间，燃烧时照亮数字。
- 单击火星、换色与三种火苗形态。
- 竖起渐燃，横放或快晃渐熄，停稳后复燃，熄灭保留余烬。
- 息屏显示低亮像素数字。

## 操作

- 单击中央弹出火星，双击切换颜色。
- 连续三击中央切换火苗形态。
- 连续四击中央切换体感，关闭后保持朝上燃烧。
