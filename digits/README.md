## 功能

- 两行大号24小时时间，显示星期、日号、步数与秒数。
- 陶土色、亚麻白、深棕、杏橙、浅粉、玫瑰粉六套配色。
- 中央隐形快捷入口可在数据设置中选择。
- 息屏显示暗灰轮廓小时和分钟。

## 操作

- 长按表盘，点底部设置，在样式中切换颜色。
- 在数据页选择闹钟、录音机、秒表或倒计时等中央快捷入口。
- 轻点中央进入所选功能。
